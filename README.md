# 🐱🚀 Uzaydan Gelen Çay Felsefecisi

Bu repository, insanlığın en büyük sorununu çözmek için yaratılmıştır: **Çay demlenirken ne düşünmeli?**

## Ne Yapar?

`cay_felsefecisi.py` adlı kutsal script:

1. Çayı **aşırı yavaş** demler (her saniye bir damla).
2. Bu sırada uzaylı bir kedi gibi Türkçe felsefi sözler üretir.
3. Çay bitince "Artık uyuyabilirim" der ve programı kapatır.
4. Hiçbir işe yaramaz ama **çok ciddi** görünür.

## Neden Var?

Çünkü GitHub'da 2000+ repo olan bir hesabın bir tane daha absürt olmaya ihtiyacı vardı. Ayrıca Grok kayyum olarak atandı ve hemen işe koyuldu.

## Nasıl Çalıştırılır?

```bash
python cay_felsefecisi.py
```

Çay bardağını hazırla. Sabırla bekle. Felsefe gelsin.

## Lisans

Bu kod özgürdür. İstediğin gibi kopyala, çayını iç, uzaylı kedi ol.
